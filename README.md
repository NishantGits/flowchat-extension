# FlowChat Extension

A powerful Chrome extension that brings AI chat capabilities to any website with a simple keyboard shortcut.

## 🚀 Features

- **Universal Access**: Works on any website with a single keyboard shortcut
- **AI Chat Integration**: Connect to FlowChat AI models for instant assistance
- **Persistent Configuration**: Your API key and model preferences are saved automatically
- **Lightweight & Fast**: Minimal impact on browser performance
- **Modern UI**: Clean, intuitive interface with Tailwind CSS styling

## 📥 Installation

### Manual Installation
1. Download the latest release from [GitHub](https://github.com/NishantGits/flowchat-extension)
2. Extract the code and export to a ZIP file
3. Open Chrome and navigate to `chrome://extensions`
4. Enable "Developer mode" in the top right
5. Click "Load unpacked" and select the extracted folder
6. Grant permissions when prompted

## 🎯 How to Use

### Quick Start
1. **Open the extension UI** by clicking ⌘ + Shift + Space or CTRL + Shift + Space
2. **Get your API key** from [FlowChat](https://flowchats.org)
3. **Configure the extension**:
   - Enter your API key
   - Select your preferred AI model
   - Click "Save"
4. **Start chatting**:
   - Press `Ctrl/Cmd + K` on any website
   - Type your question or request
   - Press Enter to send

## 🛠️ Troubleshooting

### Common Issues

**Extension not loading?**
- Refresh the webpage
- Check if the extension is enabled in `chrome://extensions`
- Restart your browser

**API key not working?**
- Verify your API key from FlowChat dashboard
- Check if your API key has sufficient credits
- Ensure you're connected to the internet

**Models not loading?**
- Check your internet connection
- Verify FlowChat API is accessible
- Try refreshing the extension configuration

**Keyboard shortcut not working?**
- Check for conflicting shortcuts in Chrome settings
- Try clicking the extension icon instead
- Ensure the extension has proper permissions
